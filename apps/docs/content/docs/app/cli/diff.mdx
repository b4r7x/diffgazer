title: dgadd diff
description: Compare installed files with bundled registry versions.
---

## Usage

```bash
pnpm exec dgadd diff [item...]
```

> **Before publication:** Diffgazer packages are not yet published to npm, so there is no `dgadd` bin until you install one. Follow the canonical [Copy-first mode procedure](https://github.com/b4r7x/diffgazer#copy-first-mode-dgadd) to build and pack `@diffgazer/add`, then install that packed tarball in the target app. The target-app install is what puts `dgadd` on `pnpm exec`.

## Examples

```bash
pnpm exec dgadd diff
pnpm exec dgadd diff ui/button ui/tabs keys/navigation
```

## What it does

1. Loads your `diffgazer.json` configuration.
2. Resolves requested items or auto-detects installed ones.
3. Compares local files against bundled registry content.
4. Prints unified diffs.
5. Shows changed, unchanged, and not-installed counts.

When no item is passed, `dgadd diff` checks every installed UI component and hook from the local manifest.

## Options

| Flag | Description | Default |
|------|-------------|---------|
| `--cwd <path>` | Working directory | `.` |
