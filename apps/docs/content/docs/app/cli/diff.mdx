## Usage

```bash
pnpm exec dgadd diff [item...]
```

> **npm packages:** `@diffgazer/add`, `@diffgazer/ui`, and `@diffgazer/keys` are publish-gated and not on npm, so there is no `dgadd` bin until you install one. Follow the [Copy-first mode procedure](https://github.com/b4r7x/diffgazer#copy-first-mode-dgadd) to build and pack `@diffgazer/add` from a checkout, then install that tarball in the target app; that install is what puts `dgadd` on `pnpm exec`. Components also install without a checkout from the hosted registry: `npx shadcn add https://r.b4r7.dev/r/ui/<item>.json`.

## Examples

```bash
pnpm exec dgadd diff
pnpm exec dgadd diff ui/button ui/tabs keys/navigation
```

## What it does

1. Loads your `diffgazer.json` configuration.
2. Resolves requested items or auto-detects installed ones.
3. Compares local files against bundled registry content.
4. Prints unified diffs.
5. Shows changed, unchanged, and not-installed counts.

When no item is passed, `dgadd diff` checks every installed UI component and hook from the local manifest.

## Options

| Flag | Description | Default |
|------|-------------|---------|
