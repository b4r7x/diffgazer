---
title: dgadd list
description: List available Diffgazer registry items.
---

## Usage

```bash
pnpm exec dgadd list
```

> **Before publication:** Diffgazer packages are not yet published to npm, so there is no `dgadd` bin until you install one. Follow the canonical [Copy-first mode procedure](https://github.com/b4r7x/diffgazer#copy-first-mode-dgadd) to build and pack `@diffgazer/add`, then install that packed tarball in the target app. The target-app install is what puts `dgadd` on `pnpm exec`.

## Examples

```bash
pnpm exec dgadd list
pnpm exec dgadd list --json
pnpm exec dgadd list --installed
```

## Options

| Flag | Description | Default |
|------|-------------|---------|
| `--cwd <path>` | Working directory | `.` |
| `--json` | Output as JSON | `false` |
| `--installed` | Show only installed items | `false` |
| `--all` | Include hidden/internal items | `false` |

## Output

Names are shown with their install namespace:

```text
ui/button
ui/dialog
keys/navigation
keys/focus-trap
keys/focus-restore
keys/scroll-lock
```
