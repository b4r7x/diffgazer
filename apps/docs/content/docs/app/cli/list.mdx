---
title: dgadd list
description: List available Diffgazer registry items.
---

## Usage

```bash
pnpm exec dgadd list
```

> **npm packages:** `@diffgazer/add`, `@diffgazer/ui`, and `@diffgazer/keys` are publish-gated and not on npm, so there is no `dgadd` bin until you install one. Follow the [Copy-first mode procedure](https://github.com/b4r7x/diffgazer#copy-first-mode-dgadd) to build and pack `@diffgazer/add` from a checkout, then install that tarball in the target app; that install is what puts `dgadd` on `pnpm exec`. Components also install without a checkout from the hosted registry: `npx shadcn add https://r.b4r7.dev/r/ui/<item>.json`.

## Examples

```bash
pnpm exec dgadd list
pnpm exec dgadd list --json
pnpm exec dgadd list --installed
```

## Options

| Flag | Description | Default |
|------|-------------|---------|
| `--cwd <path>` | Working directory | `.` |
| `--json` | Output as JSON | `false` |
| `--installed` | Show only installed items | `false` |
| `--all` | Include hidden/internal items | `false` |

## Output

Names are shown with their install namespace:

```text
ui/button
ui/dialog
keys/navigation
keys/focus-trap
keys/focus-restore
keys/scroll-lock
```
