# Support

Use GitHub issues for installation, documentation, and package support:

https://github.com/b4r7x/diffgazer/issues

Include package versions, framework, package manager, and a minimal reproduction.

Report security vulnerabilities privately through GitHub private vulnerability
reporting instead of public issues:

https://github.com/b4r7x/diffgazer/security/advisories/new

If you cannot use GitHub advisories, email b4r7dev@gmail.com instead.
